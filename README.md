# lillero-gradle
> The tool to remove boilerplate introduced by the tool to remove boilerplate introduced by the tool to remove boilerplate

`lillero-gradle`, or the Lillero Gradle Plugin, is the solution for when you *seriously don't care* about the billion
things you can configure in the processor and really just want whatever is needed to develop your mod, preferably writing
as few lines of Groovy as possible.

## Features
- Automatic lillero dependency management (including loaders).
- Detect the most appropriate mappings when possible (Loom only).
- Fancier way to control most of [`lillero-processor`](https://github.com/zaaarf/lillero-processor/)'s settings.

...and possibly more to come!
