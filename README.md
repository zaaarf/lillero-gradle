# lillero-gradle
> The tool to remove boilerplate introduced by the tool to remove boilerplate introduced by the tool to remove boilerplate

`lillero-gradle`, or the Lillero Gradle Plugin, is the solution for when you *seriously don't care* about the billion
things you can configure in the processor and really just want whatever is needed to develop your mod, preferably writing
as few lines of Groovy as possible.

## Features
- Automatic lillero dependency management (including loaders).
- Detect the most appropriate mappings when possible (Loom only).
- Fancier way to control most of [`lillero-processor`](https://github.com/zaaarf/lillero-processor/)'s settings.

...and possibly more to come!

## Configuring
What follows is a list of all possible configuration keys, with each setting's default value.

```groovy
lillero {
	// Whether this should register the custom repository implicitly.
	registerRepo = true

	// Whether this should attempt to pick the loader most suited to your environment.
	// Currently only supports loom, so it'll only add lillero-mixin.
	auto = true

	// The version string to use for each of the components.
	coreVersion = '+'
	processorVersion = '+'
	mixinVersion = '+'
	loaderVersion = '+'

	// Whether this should attempt to shadow lillero in the plugin.
	// It will not do anything unless the shadow plugin is applied.
	shadow = false

	// When set, it will generate a fake mixin at the given path.
	// It does not have a default value.
	fakeMixinFQN = 'my.package.FakeMixin'

	// Where the patches should be generated by the processor.
	// It does not have a default value, but setting fakeMixinFQN will implicitly set
	// this to the fake mixin's plugin.
	outputPackage = 'my.package'

	// Whether to force use of the specified mappings.
	// If not set, will first attempt to load the most suitable ones for your environment.
	// If it can't determine which those would be, it will default to no mappings.
	// All formats supported by the processor are accepted.
	mappings = file('/path/to/mappings.tiny')

	// The namespace to map from, if applicable.
	// Will be autodetected if unspecified and possible.
	mappingsNamespaceFrom = 'named'

	// The namespace to map to, if applicable.
	// Will be autodetected if unspecified and possible.
	mappingsNamespaceTo = 'intermediary'

	// Whether to warn about unverifiable anonymous classes.
	anonymousClassWarning = true

	// Whether to warn about manually specified fully qualified names that can't be validated.
	manualClassWarning = true

	// Whether generated IInjectors should use obfuscated names at runtime.
	obfuscateInjectorMetadata = true

	// Whether this should avoid generating service a provider file.
	noServiceProvider = false
}
```
